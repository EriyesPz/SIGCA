# 🚀 SIGCA-

---

## 📦 Ejecutar ambos servicios

```bash
pnpm turbo run dev
```
_Inicia tanto el frontend como el backend en modo desarrollo._

---

## 🌐 Ejecutar solo (web)

```bash
pnpm --filter web dev
```
_Lanza únicamente la aplicación web._

---

## 🛠️ Ejecutar solo (api)

```bash
pnpm --filter api dev
```
_Lanza únicamente la API._

---

## Ejecutar storybook
```bash
pnpm storybook
```

> _Asegúrate de tener [pnpm](https://pnpm.io/) instalado antes de ejecutar los comandos._
